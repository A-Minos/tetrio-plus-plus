# TETR.IO PLUS

TETR.IO customization toolkit for modifying block skins, sound effects, music, backgrounds and more. Additionally,
create dynamic experiences using the music graph, create and load custom maps with the map editor, and play on mobile
with completely customizable touch controls.

TETR.IO PLUS is a **third-party game modification** for TETR.IO.

See the [wiki](https://gitlab.com/UniQMG/tetrio-plus/-/wikis/home) for
more information.

## 原仓库

[https://gitlab.com/UniQMG/tetrio-plus](https://gitlab.com/UniQMG/tetrio-plus)

## 定制内容

> 缩短游戏打开时间    
> 取消阻止开发者工具    
> 新增 `SFX` 缓存    
> 初始化尝试多捕获 `window.load` 事件防止预加载失败    
> 新增插件管理器    
> 新增插件 缩小字号    
> 新增插件 降低性能指示器透明度    
> 新增插件 敏感旗帜替换    
> 新增插件 中文翻译

## Warnings

- This software is not associated with or created by TETR.IO or osk.
- Do **not** report issues to TETR.IO/osk while TETR.IO PLUS is installed.
- This extension can potentially break your game. If your game fails to load or you encounter other bugs, try removing
  the addon.
- Chromium-based browsers are not supported as [they lack](https://bugs.chromium.org/p/chromium/issues/detail?id=487422)
  an [important API](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/webRequest/filterResponseData)
  used by this project.
